# PyMKUI × h265web.js 播放回归矩阵

2026-10-11 本机复测。环境为 PyMKUI `dev-cyl/h265web.js-pro`、ZLMediaKit Python 插件版 `46220e6`、macOS Chrome、隔离的本机 ZLM 和临时数据库。测试全程使用 Chrome `--mute-audio`；h265web.js 弹窗也保持静音。下表只对所列入口、素材和操作下结论。

| 场景 | PyMKUI 入口与格式 | 视频／音频编码 | 实测操作与证据 | 结果 |
| --- | --- | --- | --- | --- |
| 直播 | RTMP 行 → HTTP-FLV | H.265／AAC | 原「播放」按钮、静音、暂停／继续、截图、关闭；1280×720，画面与媒体时间推进，读者归零 | 通过 |
| 直播 | TS 行 → HTTP-TS | H.265／AAC | 同上 | 通过 |
| 直播 | RTMP 行 → HTTP-FLV | H.264／AAC | 与 H.265 交替开关；1280×720，可见画面、帧数推进、读者归零 | 通过 |
| 直播 | TS 行 → HTTP-TS | H.264／AAC | 同上 | 通过 |
| 直播鉴权 | HTTP-FLV、HTTP-TS | H.265／AAC | 故意触发 HTTP 401，点「重试」后重新取得一次性 `on_play` 参数并出画面；旧 token 再请求仍为 401 | 两条入口均通过 |
| 直播长播 | RTMP 行 → HTTP-FLV | H.265／AAC | 替换入口连续 30 分钟；30 个逐分钟样本的媒体时间与帧数持续增长，终点约 45000 帧，画面抽检最低熵 6.11；关窗后 Worker/读者归零，0 页面异常 | 通过 |
| 直播切流 | RTMP 行 → HTTP-FLV | H.264/AAC ↔ H.265/AAC | 20 轮交替开关，各编码 10 轮；每轮有画面和帧数，关闭后读者归零，0 页面异常 | 通过 |
| 直播切流 | TS 行 → HTTP-TS | H.264/AAC ↔ H.265/AAC | 另跑 20 轮；最低截图熵约 6.31，关闭后读者归零，0 页面异常 | 通过 |
| 直播（原有入口） | HLS | H.264／AAC | 连续时间戳推流，15 秒内帧数 65→276 | 播放通过 |
| 直播（原有入口） | HLS | H.265／AAC | HTTP 200，媒体时间推进，但视频尺寸与解码帧数保持 0 | **未通过** |
| 直播（原有入口） | HLS-fMP4 | H.264／AAC | 隔离 ZLM 开启该协议，17 秒内帧数 47→320 | 播放通过 |
| 直播（原有入口） | HLS-fMP4 | H.265／AAC | 清单 200，初始 4 帧后停住，浏览器媒体错误 3 | **未通过** |
| 直播（原有入口） | HTTP-fMP4 | H.264／AAC、H.265／AAC | 两种编码都持续出帧；关窗和离开视频管理页后读者归零 | 通过；包含本次发现的原生视频释放修复 |
| 直播（原有入口） | RTSP 行 → WHEP | H.264／AAC、H.265／AAC | 两种编码均收到视频帧；关窗/离页后连接及读者归零 | 通过；原生 WHEP 视频未默认静音，测试浏览器整体静音 |
| VR 直播 | RTMP 行 → HTTP-FLV，手动 360° | ERP 源转 H.264／AAC | 平面↔透视、重置视角、截图、关窗；鼠标拖动改变 yaw/pitch，滚轮改变 fov | 通过 |
| VR 直播 | TS 行 → HTTP-TS，手动 360° | ERP 源转 H.264／AAC | 平面↔透视、重置、截图、读者释放 | 通过 |
| VR 直播 | RTMP 行 → HTTP-FLV，手动 360° | ERP 源转 H.265／AAC | 同上 | 通过 |
| VR 直播 | TS 行 → HTTP-TS，手动 360° | ERP 源转 H.265／AAC | 同上 | 通过 |
| VR 直播 | RTMP 行 → HTTP-FLV，原片直接复制 | H.264／无音轨 | HTTP 200、读者数 1，但 12 秒内仍无首帧、尺寸和帧数为 0 | **未通过**；规范化转码流的成功不能覆盖此结果 |
| 点播 | 录像管理 → MP4 | H.264／AAC、H.265／AAC | 两种文件均经 PyMKUI 文件接口静音出画面，暂停、seek 3 秒、继续和关闭通过 | 通过；使用原生 `<video>`，不经过 h265web.js |
| VR 素材点播 | 录像管理 → ERP MP4、ERP WebM | H.264／无音轨、VP8／无音轨 | 两种文件均能平面播放，暂停/seek/继续通过；录像弹窗没有 360°控件 | **平面点播通过；VR 观看未接入** |

本次录入隔离数据库的短片只用于测试 PyMKUI 的点播入口，不代表录像生成流程通过。PyMKUI 视频管理页没有 WS-FLV/WS-TS 播放行；触屏 VR 手势、其他浏览器、线上代理/vhost 均不在这次本机结论内。

一轮切流曾被固定“中心熵 > 2”断言在第 14 轮中断。该帧与原始 `video40.flv` 精确解码的 `TCG +00:01:29:14` 深色淡出片头一致，并非播放器黑屏；改用后续帧数、时间和像素变化复核后，从第 1 轮重新跑完 20 轮，没有拼接两次运行的结果。
